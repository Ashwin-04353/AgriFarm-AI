# AgriFarm-AI

AgriFarm-AI is an AI-powered smart agriculture platform that enables farmers to monitor field conditions, upload farm data, analyze insights, and receive intelligent recommendations and advisories based on soil health and environmental factors.

## Features

- AI Advisory Agent
- Farm Analytics Dashboard
- Field Monitoring
- Alert Management
- CSV Data Upload
- SQL Database Integration
- FastAPI Backend
- Interactive Charts and Insights

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Tailwind CSS
- Chart.js

### Backend
- Python
- FastAPI
- SQLAlchemy

### Database
- SQL Server

### AI
- Groq API
- LLM-based Advisory Agent

## How to Run

1. Clone the repository
2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Configure environment variables

```env
GROQ_API_KEY=your_api_key
```

4. Start backend

```bash
python run.py
```

5. Open frontend pages in browser
